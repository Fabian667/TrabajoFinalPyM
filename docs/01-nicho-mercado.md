# Nicho de Mercado: PyMES de Fabricación de Muebles de Madera

## Descripción del Nicho
El ERP está diseñado específicamente para pequeñas y medianas empresas dedicadas a la fabricación de muebles de madera.

## Características del Nicho
- **Tamaño**: 5-50 empleados
- **Procesos típicos**: Corte de madera, ensamblado, lijado, pintado/terminación, empaque
- **Dolores principales**:
  - Control de inventario deficiente de materias primas
  - Seguimiento manual de órdenes de producción
  - Falta de integración entre producción y ventas
  - Dificultad para calcular costos reales de productos
  - No tienen presencia en línea o es limitada

## Ventajas Competitivas
1. Especialización en procesos de madera
2. Integración nativa con ecommerce
3. Fácil de usar para personal no técnico
4. Precio accesible para PyMES
